5 · Theme switcher (try it — it works here)

Three-state segmented control in the header, next to the version badge: Auto (default, follows the OS), Light, Dark. Persisted in localStorage.

Implementation is nearly free: the app is already 100% light-dark(), so the switcher just sets color-scheme: light / dark on :root (Auto removes it). The one exception — the dark diff variables behind @media (prefers-color-scheme: dark) — converts to light-dark() values scoped on .diff-wrapper, which also keeps the 035 proximity-over-order guarantee. This mockup's switcher uses exactly that mechanism.

1 · Badges: filled instead of empty

One rule fills all fifteen badge variants: background: color-mix(in srgb, currentColor 13%, transparent) — the tint derives from each badge's existing hue, text color and contrast stay untouched. Solid fill is shown for comparison but recommended against: white-on-yellow and white-on-muted fail contrast at 0.7rem, and eleven saturated chips overpower the tree rows they annotate.

2 · One <CopyButton> component

Today there are three unrelated implementations (CopyMarkdownButton, an inline handler in MigrationSteps, plain toolbar buttons), each hand-rolling its own "Copied!" timeout. Proposed: one component — clipboard icon, label, shared copied-state (icon flips to a check). One size everywhere: any control that copies something looks and measures the same, wherever it sits. 3 + 4 · Diff chrome: copy the stage result, fix the toolbar

Frontend-design critique of the current JsonDiff toolbar:

  • The lone button says "Side-by-side" while unified is active — it labels the action, not the state (this already caused confusion in the 035 review). A segmented control shows both modes and which one you're in.
  • It's an unstyled default button, inconsistent with the app's existing segmented pattern (.preset-view-toggle on the Presets tab).
  • "Show all" hides inside an empty-note below the diff — footer bar with a real button instead.
  • The row floats over the diff with no visual anchor — it becomes a chrome bar (surface background, bottom border), the same grammar as every card title.
